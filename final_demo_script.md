# AI Accessibility Study Aids — Final Demo Script

**Estimated time:** 3–4 minutes  
**Project:** AI Accessibility Study Aids  
**Purpose:** Demonstrate how the website presents AI study topics in accessible formats.

## 1. Introduction

Hello. My project is called **AI Accessibility Study Aids**. It is designed to make introductory AI concepts easier to study by providing simplified notes, visual summaries, audio support, and short quizzes.

## 2. Demonstrate the website

1. Open `index.html` in the browser.
2. Show the home page and the five topics: Machine Learning, Natural Language Processing, Computer Vision, Neural Networks, and Generative AI.
3. Click **Machine Learning** from the topic list to demonstrate that the lesson link opens the correct section.
4. Show the easy-English explanation and key terms.
5. Show the visual summary or mind map.
6. Play the Machine Learning MP3 audio player, if `audio/ml_basics.mp3` is present in the project folder. Also demonstrate the browser text-to-speech button if it works.
7. Answer the Machine Learning quiz questions and click the check button to show the score.
8. Open the Verification Report section and explain what has been checked and what still needs evidence.

## 3. Explain the repeatable process

The process is:

1. Select an original learning resource.
2. Identify the key ideas and terminology.
3. Draft a simpler version for beginners.
4. Create a short audio script and visual summary.
5. Compare the simplified content with the original source.
6. Ask human reviewers for feedback and revise the material.
7. Document the prompts, checks, and limitations.

## 4. Accuracy and limitations

AI-generated summaries can omit details, change meaning, or contain errors. A simplified explanation should not be treated as verified until it has been compared with the relevant original material. Audio playback does not itself prove that the content is accurate. Human review is important.

## 5. Report the project status honestly

Before presenting, update this section using the actual work completed:

- Original resource selected: MIT OpenCourseWare, *Introduction to Machine Learning*.
- Website topics and interactive features: check the final site before presenting.
- MP3 audio: confirm that the file exists and plays from the project folder.
- Source verification: list only concepts that were actually checked against the relevant original lesson or reading.
- AI-tool comparison: enter actual outputs from three AI tools and compare them; do not invent results or scores.
- Peer review: include feedback from three real reviewers only after they have reviewed the website and submitted their comments.
- AI skills and tools: list the skills demonstrated and the tools actually used in the project.

## 6. Closing

This project brings simplified study notes, visual summaries, audio support, and quizzes together in one website. The goal is to improve access to learning, while keeping source checking and human review as important parts of the process.
