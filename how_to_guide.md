# AI Accessibility Study Aids — One-Page How-to Guide

## Goal
Turn a lesson from an open educational resource into easier text, a short audio version, and a visual summary without changing the original meaning.

## Repeatable process
1. **Choose a source.** Pick one lesson from a reliable open educational resource. Save its title, URL, lecture/page number, and the date you accessed it.
2. **Keep the original.** Copy only the selected passage you need and record where it came from. Do not replace the source with an AI summary.
3. **Write simplified text.** Ask an AI assistant to use short sentences and familiar words, define technical terms, retain key facts and caveats, and avoid adding unsupported claims.
4. **Create accessible formats.** Turn the checked simplified text into a short spoken script and a visual summary (for example, a mind map). Use readable contrast, clear labels, and meaningful alt text where appropriate.
5. **Verify against the source.** Compare each definition and example with the original. Mark each item **Verified**, **Needs correction**, or **Not yet checked**. Correct omissions, exaggerations, and inaccurate wording before publishing.
6. **Compare AI tools.** Give the same prompt and source passage to at least three AI tools. Save each output. Compare factual accuracy, missing ideas, readability, tone, and usefulness using the same checklist. Do not assume the longest answer is best.
7. **Ask people to review.** Ask three peers to review clarity and usefulness. Record their real comments, what they found confusing, and what you changed. Do not invent responses.
8. **Revise and document.** Update the text/audio/visual summary, record changes in the verification report, and make a before/after table.
9. **Test the final demo.** Check that lesson links, audio controls, visuals, quizzes, and report links work with a keyboard and in a browser. Note any limitations.

## Suggested free-tier tool workflow
- **ChatGPT:** draft simplified text and a short audio script; ask for a verification checklist.
- **Gemini:** create an independent simplified version from the same source passage.
- **NotebookLM:** ask source-grounded questions or generate a source-based overview, if available in your account.
- **Canva:** lay out the checked concepts as a visual summary/infographic.
- **ElevenLabs or a browser text-to-speech tool:** create/play audio. If using browser speech synthesis, state clearly that it is not a downloadable audio file.
- **Microsoft Immersive Reader:** review readability and listen to text where available.

Use at least four tools overall and record which tool actually performed each task. Tool access/features can vary by account. Never write that a tool was tested unless you actually ran it.

## Reusable prompt
> Using only the source passage below, rewrite it for a beginner in simple English. Preserve all important meanings, definitions, examples, and limitations. Do not add facts that are not supported by the passage. List any terms that need checking. Then create (1) a 30–60 second audio script and (2) a mind-map outline. Keep the original source URL/title visible. Source passage: [paste passage].

## Human verification checklist
- Are the main ideas and important caveats preserved?
- Are definitions and examples supported by the source?
- Is the wording easier without becoming misleading?
- Are audio and visual content consistent with the checked text?
- Are peer comments real and recorded accurately?
- Are AI-tool differences documented with actual outputs?

## Limitations
AI may omit details, introduce errors, or use an unsuitable tone. Audio generation and visual layout can introduce extra errors. A human must compare outputs with the source and review them before students rely on them.
