## Simplified text: Machine Learning Basics

Machine Learning (ML) is a part of Artificial Intelligence (AI). It helps computers learn patterns from data and use those patterns to make predictions or decisions.

**Data** means information, such as numbers, words or pictures. A **model** is a system that learns from examples and uses what it learned to make predictions.

### Two learning approaches

- **Supervised learning:** The computer learns from examples that include the correct answers.
- **Reinforcement learning:** The computer learns by taking actions and receiving rewards or other feedback. It can use this feedback to improve its choices.

### Learning well on new data

- **Overfitting:** A model fits its training examples too closely. It may then perform poorly on new examples.
- **Generalization:** A model uses what it learned to make useful predictions on data it has not seen before.

### Everyday example

Imagine a computer learning to recognise cats in pictures. During supervised learning, it studies pictures labelled “cat” or “not cat.” If it only memorises the pictures used for training, it may struggle with a new cat picture. If it has learned patterns that also work on new pictures, it is generalizing.

This is an illustrative example created for learners; it is not presented as a quotation from the MIT material.

## Visual summary: four key points

1. **Machine Learning:** Find patterns in data to make predictions or decisions.
2. **Supervised learning:** Learn from examples with correct answers.
3. **Reinforcement learning:** Improve choices using actions and rewards or feedback.
4. **Overfitting vs. generalization:** A model should do more than fit its training examples; it should also work on new data.
