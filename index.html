1. Machine Learning (ML)

Explanation

Machine Learning is a branch of AI that allows computers to learn patterns from data and make predictions or decisions without being explicitly programmed for every situation.

Easy English Version

Machine Learning (ML) is part of Artificial Intelligence (AI). It helps computers learn patterns from data and make predictions.

Example: An email system can learn to find spam messages by studying examples of spam and normal emails.

Supervised learning: Learns from examples that have correct answers.

Reinforcement learning: Learns by taking actions and receiving rewards or penalties.

Overfitting: The model learns its training examples too closely and may do poorly on new examples.

Generalisation: The model can use what it learned on new data.

Machine Learning in Simple Steps

  1. Collect data: Gather examples.
  2. Train the model: Let the computer find patterns.
  3. Test the model: Check it with new examples.
  4. Make a prediction: Use the learned patterns.

Important Words

Data: Information used for learning.

Model: The system produced by the learning process.

Training: Learning patterns from examples.

Prediction: The model's output for new information.

Overfitting: Learning training examples too closely.

Generalisation: Working well on unseen examples.

Visual Summary

Machine Learning
1. Collect Data 2. Train Model 3. Test Model 4. Predict

Short Audio Script

Machine learning is a part of artificial intelligence. It helps computers learn from data and make predictions. For example, an email system can learn to identify spam messages. In supervised learning, the computer learns from examples with correct answers. In reinforcement learning, it learns through actions and rewards. Overfitting happens when a model learns training examples too closely. Generalisation means using what it learned on new data.

Original learning resource: MIT OpenCourseWare — Introduction to Machine Learning

2. Natural Language Processing (NLP)

Explanation

Natural Language Processing is a field of AI that helps computers process, understand and generate human language. It works with written text and spoken language.

Example: Chatbots, language translation and speech assistants use NLP to interact with people.

Easy English Version

NLP helps computers work with human language. Human language includes the words we write and the words we speak.

Text classification: Places text into groups, such as spam or not spam.

Sentiment analysis: Estimates whether a message sounds positive, negative or neutral.

Speech recognition: Changes spoken words into text.

Summarisation: Makes a shorter version of longer text while keeping its main ideas.

How NLP Works

  1. Receive language: Get text or speech.
  2. Process it: Analyse words and their context.
  3. Find patterns: Predict the likely meaning or task.
  4. Give a result: Translate, summarise or respond.

Important Words

Language model: Learns patterns in language.

Translation: Expresses meaning in another language.

Context: Information that helps explain a message.

Sentiment: A feeling or opinion in a message.

Limitation: NLP may misunderstand slang or ambiguous words.

Visual Summary

Natural Language Processing
Text / Speech Language Analysis Translation Summary / Answer

Short Audio Script

Natural Language Processing, or NLP, helps computers work with human language. Translation apps, chatbots and voice assistants use NLP. Sentiment analysis estimates whether a message is positive, negative or neutral. Speech recognition changes spoken words into text. NLP can make mistakes when words have several meanings or when context is unclear.

3. Computer Vision

Explanation

Computer Vision is a field of AI that enables computers to analyse images and videos. It helps systems identify objects, faces, scenes and visual patterns.

Easy English Version

Computer Vision helps computers understand information in pictures and videos.

Example: A photo app can group pictures that contain dogs. A driver-assistance system may detect cars, people or road signs.

Image classification: Gives an image a label, such as “cat”.

Object detection: Finds objects and their locations in an image.

Image segmentation: Separates an image into areas or objects.

How Computer Vision Works

  1. Get an image: A camera or file provides visual data.
  2. Prepare the data: Format the image for the model.
  3. Find patterns: Look for shapes and other features.
  4. Return a result: Classify the image or identify objects.

Important Words

Pixel: A tiny element that forms a digital image.

Label: The name of an object or image category.

Detection: Finding an object and where it is.

Limitation: Results can be affected by poor lighting, blurry images or limited training examples.

Visual Summary

Computer Vision
Images Visual Patterns Classification Object Detection

Short Audio Script

Computer Vision helps computers analyse images and videos. Image classification gives an image a label, such as cat or car. Object detection finds objects and shows where they are. Computer Vision can support photo search and driver assistance. Its results can be affected by blurry pictures, poor lighting and limited training examples. Important decisions should be checked by people.

4. Neural Networks

Explanation

Neural Networks are machine learning models made of connected artificial neurons. Their layers learn patterns from data.

Easy English Version

A neural network is a type of machine learning model made of connected mathematical units.

Example: A model can study pictures of handwritten numbers and learn to recognise numbers in new pictures.

Input layer: Receives information.

Hidden layers: Learn useful patterns.

Output layer: Gives a prediction or result.

Training: The model compares its predictions with the target and adjusts its parameters to reduce error.

How a Neural Network Learns

  1. Input: Give the model data.
  2. Calculate: Information moves through the layers.
  3. Predict: The output layer gives an answer.
  4. Adjust: The model updates its parameters during training.
  5. Repeat: Training continues to improve performance.

Important Words

Neuron: A mathematical unit that processes inputs.

Weight: A value adjusted as the network learns.

Training: Adjusting model parameters using examples.

Loss: A measure of prediction error.

Limitation: Neural networks may need suitable data and computing resources, and their predictions can be difficult to explain.

Visual Summary

Neural Network
Input Layer Hidden Layers Output Layer Training Predictions

Short Audio Script

A neural network is a machine learning model made of connected mathematical units. The input layer receives data, hidden layers learn patterns, and the output layer gives a result. During training, the network compares its prediction with the target and adjusts its weights to reduce error. Neural networks can recognise images and process language, but they may need lots of data and their decisions are not always easy to explain.

5. Generative AI

Explanation

Generative AI creates new content based on patterns learned from training data. It can generate text, images, audio and code.

Easy English Version

Generative AI is a type of AI that creates new content by learning patterns from examples in training data.

Example: A student can ask an AI tool to draft a short explanation of a topic or create an illustration.

Prompt: Instructions given to the AI tool.

Generated output: The content produced by the tool.

Human review: A person checks the content for accuracy and suitability.

How Generative AI Works

  1. Write a prompt: Explain what you need.
  2. Process the prompt: The model uses learned patterns.
  3. Generate content: The tool creates an output.
  4. Check the result: Verify important facts and improve unclear parts.

Important Words

Prompt: Instructions given to an AI model.

Training data: Examples used to train the model.

Hallucination: Information that sounds correct but may be false or unsupported.

Bias: A problem that can produce unfair or unbalanced outputs.

Limitation: Generated content can contain mistakes or omit important information. Human review is necessary.

Visual Summary

Generative AI
Prompt AI Model Generated Content Human Review Improved Result

Short Audio Script

Generative AI creates new content, such as text, pictures, audio and computer code. The user gives it a prompt that tells the tool what to make. It can draft simple study notes. However, generated content can include incorrect facts or bias. Always check important information against reliable sources and have a person review the result before using it for learning.
